# Local paper library

Downloaded papers live in `papers/`; extracted text for local inspection lives
in `text/`. These files are kept out of git. The source URLs, retrieval status,
hashes, and bibliographic records are tracked under
[`doc/literature/`](../doc/literature/README.md).

The library uses publicly accessible publisher, proceedings, institutional,
and preprint copies. A download does not imply that every result in that paper
was independently verified. See the evidence-level field in the bibliography.
