\section{Protocol details}
\label{app:protocol}

\subsection{Motif library and matching constraints}
The body alphabet is $\{\mathrm A,\mathrm B,\mathrm X\}$. The five primitive motifs are \texttt{AXAXAXBXBXBX}, \texttt{AXAXBXAXBXBX}, \texttt{AXAXBXBXAXBX}, \texttt{AXBXAXAXBXBX} and \texttt{AXBXBXAXAXBX}. Each has three A, three B and six X; cyclic bigram counts $\mathrm{AX}=3$, $\mathrm{XA}=3$, $\mathrm{BX}=3$, $\mathrm{XB}=3$; all runs of length one; first symbol A and last symbol X with final bigram BX. Dwell $q$ repeats each symbol $q$ times; the primary condition is $q=1$. For horizon $R$ the periodic body is one motif repeated $R$ times; the control body draws $R$ motif identifiers uniformly, sets the last to the periodic motif, and is rejected if the resulting symbol string has a proper whole-string period (an exact tiling by a shorter string). At $R=1$ the arms are identical. Pairs share the WRITE prefix (required and nuisance values), the query index, the horizon and the total number of updates; no arm or schedule indicator is given to the model. The generator stores every motif identifier and the realized symbol string so that the actual inputs, not the arm name, are verified.

\subsection{Episode rendering}
Observation types are WRITE, A, B, X and QUERY (five indicators); WRITE observations add a coordinate indicator (sixteen) and either a categorical value indicator (sixteen) or a real value (one channel), for 38 channels in total. The required coordinates are written first (indices 0--7), then the nuisance coordinates (8--15). The QUERY reveals the selector in $\{0,\dots,7\}$ only at the terminal step; the body never carries values. The explicit streaming register oracle, the uniform categorical predictor (population cross-entropy $\log16$) and the continuous zero predictor (population MSE $1/3$, normalized MSE one) are the fixed references.

\subsection{Competence ladder}
Each stage has a fixed maximum schedule; transitions occur only at stage boundaries and only if the preceding gate passes; no extra steps or relaxed thresholds after a failure.
\begin{enumerate}[leftmargin=2em,itemsep=1pt]
  \item Renderer and streaming oracle: exact categorical recovery and continuous error below $10^{-12}$ on CPU fixtures for zero body and $R\in\{1,2,16\}$; shuffled memories must destroy oracle agreement and shuffled query indices must select the changed coordinate.
  \item Single WRITE, immediate QUERY (500 updates): a separate two-update constructor; small-batch overfit, then held-out value generalization, with gradient and parameter-change checks.
  \item All sixteen WRITEs, zero body (500 updates): acquisition of all eight required coordinates despite the later nuisance writes.
  \item Deterministic equal $R0/R1$ exposure (500 updates), then equal $R0/R1/R2$ exposure (500 updates): coordinate-wise gates in both arms with the shared $R=1$ anchor.
  \item Long-horizon exposure (1,500 updates): deterministic equal $R1/R2/R4/R8/R16$ exposure with balanced arms and short-horizon rehearsal; the selected weights are then fixed for all memory evaluation.
\end{enumerate}
The discovery grid keeps hidden size 128, encoder size 64, AdamW, weight decay $0.01$, clipping $1.0$, batch 32, learning rates $\{5\times10^{-4},10^{-3},3\times10^{-3}\}$ frozen in advance, discovery seed 0 in each of the four model/task cells (at most twelve fits, at most 3,500 updates each). Validation manifests are fixed and evaluated every 100 updates with 128 independent episodes per query coordinate, horizon and arm. The gate is categorical accuracy at least $0.95$ or continuous normalized MSE at most $0.05$ on \emph{each} required coordinate at $R0$, $R1$ and $R2$ in both arms. Final selection uses minimum balanced validation task loss over the trained horizons among gate-passing checkpoints, earliest on ties; learning rate by the same rule, then frozen grid order. If no candidate qualifies, the grid stops and acquisition is reported unresolved. Fresh seeds 1 and 2 are then run under the frozen protocol as pilots; confirmation uses untouched seeds and test manifests under a separately frozen effect-size and uncertainty rule. \todo{Insert the frozen configuration name, seed list and compute envelope from experimental-design-v2 once recorded.}

\subsection{Capture points and native query check}
For the same held-out memory and fixed driver, capture the complete native state after the WRITE prefix, immediately before QUERY at each evaluated horizon, and immediately after QUERY. For LSTM retain $h$ and $c$ with separate measurements. Query evaluation forks from the pre-query state, applies the native QUERY update and the original head, and is verified against uninterrupted native forward execution on an identical episode. No decoder with access to labels or cues substitutes for the native readout.

\subsection{Cue-conditioned clouds and probes}
For each fixed driver history and arm: 512 training cues and 256 held-out cues, nuisance values fixed within the cloud; two driver panels per horizon in v1 (eight driver pairs and sample-size convergence checks are the research-plan default). Probes are ridge regressions (ridge $0.01$) on train-only standardized features with a $10^{-8}$ feature-scale floor, fit separately per driver and arm, with shuffled-label controls; report feature-floor counts and effective gains alongside accuracy or MSE. Geometry is reported as in \cref{sec:setting}, with raw and declared-standardized sensitivity analyses.

\subsection{Periodicity and tangent assay (v1 contract)}
Two driver panels with two cue histories sharing nuisance values; horizons $R\in\{1,2,16,32\}$ ($R=32$ is an analysis extension, not a training horizon); native float32 and fixed-weight float64 replay from the zero state through WRITE and body; closure compared over the last two phase-matched twelve-step cycles including boundaries ($R-1$ comparisons at horizon $R$; none at $R=1$). Sixteen dense twelve-step tangent windows per cell (two panels, two arms, two precisions, $R\in\{2,16\}$) at the first cue history, with the preceding window retained for phase comparison; products are formed in the saved dtype and with float64 accumulation; eigenvalues, spectral radius, singular values and largest gain are reported separately, and $\log(\text{gain})/12$ is a finite-window rate. Checks: adapter-versus-native equivalence, ordered-product versus direct twelve-step autodifferentiation, autograd JVP, and central finite differences along a fixed normalized direction. Tolerances are in \cref{sec:reproducibility}; because the FP32 state tolerance (absolute $10^{-7}$) is below the float32 half-ULP $L_2$ floor of a $13\times128$ block ($\approx2.4\times10^{-6}$ at unit scale), closure residuals are to be reinterpreted in float32 ULP units at the measured state scale, with the FP64 replay as the reference, and the v2 contract declares closure tolerances in those units. A closure pass is an approximate-closure-compatible observation; every product retains the finite-time label; no certified Floquet multiplier is reported from this assay.

\subsection{Calibration fixtures}
Measurement calibration (ten checks): isotropic four-feature covariance with $\PR=4$; rank-one covariance with $\PR=1$; a contracted rotation with four-step multiplier modulus $0.8^4=0.4096$; a nonnormal matrix with spectral radius $0.8$ and singular gain above one; a stable periodically forced response that closes its four-step orbit with multiplier modulus $0.5^4=0.0625$; zero-variance normalized dimension flagged undefined. Mechanism calibration (36 checks in seven families): affine ordering null (equal centered cue clouds and exact cue component across two body orders, offset explains linear error, offset-corrected linear and tanh readout errors vanish, native linear and nonlinear errors can differ, pooled body conditioning rejected); commuting ordering null (equal products and clouds, process-noise covariance can depend on order); noncommuting construction (products, clouds and terminal-noise linear risk differ; explicit chronology); amplitude-only decay ($\PR$ preserved, variance decays exactly); categorical forced basins (labels retained, within-basin convergence, closed two-step reference, zero reference derivative, contracting and invariant neighbourhood, terminal closure, basin separation); continuous neutral memory (required coordinates retained, neutral required directions, nuisance contraction, task-preserving dimension reduction); fresh noise without old memory (covariance sustained, analytic linear decoder risk matched, recovery deteriorates, $\PR$ remains high). All pass locally and on Narval CPU job 5234514. \evidence{infrastructure}

\subsection{Graph adapter gate (Gate D prerequisite)}
Pin an immutable upstream T-GRAB commit and dataset revision; recover or reconstruct the GC-LSTM configuration (width, layers, convolution, directed/undirected convention, candidate pair set, self-loops, loss, optimizer, truncation); implement the exact complete-state recurrence with state $2NH$ and a flattening manifest; verify prediction chronology ($G_t$ must not expose $G_{t+1}$); validate full-period autodifferentiation, stepwise products, JVP and finite differences on a tiny graph against dense products; reproduce persistence, EdgeBank, memoryless and untrained baselines with per-time exhaustive-pair F1; only then run a bounded seed on AB and AABB to resolve the legacy task identity. Absent artifacts make the work a reconstruction, labelled as such. \evidence{planned}
