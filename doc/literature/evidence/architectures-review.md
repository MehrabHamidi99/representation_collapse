The broad claim that repeated recurrent computation causes dimensional collapse is already occupied. The potentially defensible contribution is **periodicity-specific loss of required history in bounded full-state streaming models**, distinguished from ordinary elapsed-time forgetting, nuisance compression, recurrent-depth token homogenization, and readout failure. The current plan has the right matched-driver and categorical-versus-continuous controls, but novelty depends on their actual results.

## Closest full-text overlaps

**MeSH — direct dimensional-collapse overlap.** Sections 2 and 4.1, Figures 1 and 5, diagnose recursive transformer hidden-state spectral decay; Section 3.2 adds an explicit buffer and read/write routers. Their measured matrix is tokens-by-features, with the first 50 singular values normalized by the largest. This is not a cloud of full states conditioned on different required histories. Routers have iteration-specific parameters, and the buffer increases persistent state, so the intervention changes both the effective map and memory resources. A new paper cannot present recursive-transformer dimensional collapse or explicit-memory mitigation as a new discovery. [Primary full text](https://arxiv.org/html/2510.07739v1), [accepted-paper source](https://openreview.net/attachment?id=IhTrFvY7p3&name=pdf).

**Stability and Generalization in Looped Transformers — direct theory overlap.** Sections 4–5 and Appendices A.6–A.8 contrast autonomous iteration with input recall and derive the stable fixed-point sensitivity `(I-J)^-1 B`. The autonomous isolated-fixed-point result assumes smoothness and parameter transversality; it does not exclude deliberately constructed neutral memory manifolds or useful categorical basin selection. Input reinjection and initial-state contraction must be separated. Neither the recall formula nor the distinction between smooth equilibrium memory and isolated attractors should be claimed as new here. [Primary full text](https://arxiv.org/html/2604.15259v1).

**Think Shallow, Solve Deep — strongest spectral-and-behavior overlap.** Sections 3.4–3.5, 4 and 6 already compare recurrent reasoners under shared algorithmic protocols using Jacobian diagnostics, top-eight QR Lyapunov exponents, dimension proxies, and objective ablations. Appendix E explicitly limits partial spectra and projected normality; Appendix G discusses normalization confounds. These input-conditioned depth loops address task solution, rather than once-written streaming tags under matched periodic interference. Adding spectra to several recurrent architectures is therefore insufficient novelty. [Primary full text](https://arxiv.org/html/2608.18222v1).

**All Routes Lead to Collapse — strong scope overlap, weaker causal warrant.** Sections 5 and B.2–B.5 examine GAT, Mamba, RWKV-4 and depth routing, with routing interventions and key-geometry rank measurements. This precedes a cross-architecture collapse narrative, but does not test required history under periodic forcing. Reviewer concern: B.4 describes a token-position permutation null for a centered Gram/distance singular spectrum. A simultaneous row permutation gives `G' = P G P^T`, leaving that spectrum unchanged. Reported real-versus-shuffle gaps need code/null clarification; the text acknowledges this degeneracy for graphs. Gate/decay ablations also do not identify metric inadequacy against every competing mechanism. This critique is a mathematical inference from the written method, not a verified code defect. [Primary full text](https://arxiv.org/html/2606.22325v1).

**Demystifying the Token Dynamics of Deep Selective State Space Models — SSM dynamics overlap.** Sections 3–5 study a depth-continuum surrogate and scalar S6 convergence/divergence regimes, then change initialization and token ordering. Theorems 4.1, 4.3 and 4.4 concern this idealization; they are not full-state Floquet results for exact temporal recurrence under a periodic drive. Novelty must explicitly distinguish the recurrence axis and the measured ensemble. [Primary full text](https://arxiv.org/html/2410.03292v2), [ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/756dfc9113ae4f310847530403fcb212-Paper-Conference.pdf).

**LoopUS — stabilization overlap.** Section 3.1, Equations 3–8, mixes a pretrained block proposal with its prior state using a learned gate. The authors explicitly concede that convex interpolation does not prove global contraction. Sections 4.5–4.6 use latent trajectories and component ablations. This is useful competing evidence that smaller displacements can accompany improved performance, but it does not establish periodic-history loss. A gate in `(0,1)` is not a bound on the composite Jacobian when both the proposal and gate depend on state. [Primary full text](https://arxiv.org/html/2605.11011v1).

Additional substantive checks: Huginn Sections 3.1 and 4.3 document input reinjection, recurrence-induced inter-token collapse during training, and a separate state-ignoring failure (Figure 5). Setting the Record Straight Section 3 analyzes fixed attention/value-projection matrices and distinguishes spectral smoothing from sharpening. Fixed-Point Reasoners Section 3 gives sufficient contraction conditions and a damping controller; the controller's changing damping, patience and residual record must be included when analyzing the executed dynamics. [Huginn](https://arxiv.org/html/2502.05171v1), [oversmoothing analysis](https://arxiv.org/html/2401.04301v2), [Fixed-Point Reasoners](https://arxiv.org/html/2606.18206v1).

## Architectural context and terminology controls

Dong et al.'s pure-attention result excludes skip connections and feed-forward layers; Noci et al. study rank and gradients at initialization. Neither proves universal inference-time history loss for a modern full transformer. Universal Transformers, ALBERT, DEQ and programmed looped transformers establish the history and expressive possibilities of shared parameters. Xu and Sato show that loop-index conditioning can improve approximation: this conditioning changes the iteration map unless its clock is part of the state. [Pure attention](https://proceedings.mlr.press/v139/dong21a.html), [initialization analysis](https://papers.nips.cc/paper_files/paper/2022/hash/ae0cba715b60c4052359b3d52a2cff7f-Abstract-Conference.html), [loop approximation](https://proceedings.mlr.press/v267/xu25x.html).

S4, Mamba and Mamba-2 provide different state-space controls; matrix-memory RWKV-7, xLSTM and Gated DeltaNet prevent treating every recurrent transition as an input-gated diagonal decay. Block-Recurrent Transformers operate over temporal blocks. Parameter count, persistent state bytes, input access and recurrence clock need separate accounting. Arbitrary copying lower bounds are a competing capacity explanation, but the proposed fixed-size tag set avoids increasing the required information with horizon. [Copying capacity](https://arxiv.org/abs/2402.01032), [Mamba-2 duality](https://arxiv.org/abs/2405.21060), [Block-Recurrent Transformers](https://arxiv.org/abs/2203.07852).

The recent Cirrincione preprint makes exact-rank, LayerNorm and residual claims. Only its abstract/introduction were checked: it is a follow-up proof-audit target, not settled evidence. Finite algebraic rank can remain full while singular values become tiny, so exact-rank preservation cannot settle effective dimension or robust memory. [Primary preprint](https://arxiv.org/abs/2604.23681).

## Strongest likely rejection and actual gap

A skeptical reviewer can reasonably say: “The work combines known attention homogenization, known fading of bounded recurrent memory, known input-conditioned fixed points, and already-published spectral diagnostics. Repeating one motif simply creates a predictable attractor; a lower rank curve adds no causal explanation of useful information loss.” The rebuttal requires an intervention showing **excess loss from periodic ordering at identical elapsed horizon and local statistics**, with history-conditioned full-state geometry and task-relevant sensitivity predicting or mediating that excess. It also needs successful categorical-attractor and persistent-input controls, rather than defining their success away.

The six closest audits above did not reveal the plan's exact matched-motif streaming experiment. That is a bounded search finding, not proof of absence. Cross-modal rendering by itself adds breadth; transfer of a preregistered mechanism after the vector experiment adds stronger evidence. A theorem would need architecture-specific assumptions, an observable error/noise criterion, and explicit separation of local tangent contraction from global basin capacity.

## Minimal competing mechanisms and falsification

Keep four mechanisms distinct: ordinary retention/forgetting from gates or finite-precision decay; overwrite/interference that is specific to periodic ordering; useful nuisance compression with preserved required tags; and apparent collapse confined to a readout, token matrix or normalization metric. In depth loops add original-input reinjection and step conditioning as explicit interventions rather than pooling them with temporal recurrence.

The strongest initial falsification is the existing fixed-history experiment: train identical bounded-state cores to criterion, write the same required and nuisance tags once, then compare periodic and varied-order motifs at matched horizon, symbol counts, cyclic bigrams and final motif. Hold the driver fixed when estimating the cue-conditioned state cloud. Query only required tags and examine decoder-independent history sensitivity as well as the readout. Preregister a smallest meaningful excess-forgetting effect. If periodicity produces no excess within that margin despite measured contraction, or only nuisance/readout geometry shrinks while required information survives robust perturbation, the proposed harmful periodic-collapse mechanism is falsified for that regime. Longer test horizons alone would not rescue it.

## Practical measurement safeguards

Represent each step as a pure function of a complete tensor-tree state and an input. Include cell/matrix memories, normalizers, stabilization variables, convolution histories, bounded KV caches, block indices, and adaptive-controller state where applicable. Audit mutable buffers and in-place operations. A growing cache changes state dimension with horizon; report it separately. A transformer loop reading the whole fixed motif has period one in loop time, not the motif's token period. Floquet terminology requires demonstrated orbit closure, including possible subharmonics; otherwise use finite-time products.

For a trajectory use JVPs to apply `P = J_(T-1)...J_0` and VJPs in reverse to apply `P^T`, avoiding a dense state Jacobian. Independently calibrated random probes estimate `tr(P^T P)` from `||Pz||^2`; probes of `(P^T P)z` estimate `tr((P^T P)^2)` from their squared norms. Report uncertainty and probe-count sensitivity before forming a participation-ratio estimate. Leading singular modes via a matrix-free normal operator measure tangent stretching; Arnoldi on a validated closed-orbit `P` estimates selected multipliers. A top-k set cannot give an uncensored attractor dimension or full stable-rank denominator.

For centered history samples in matrix `X`, use streaming sums or two-pass mean removal for `tr(C)`, and covariance actions `v -> X^T(Xv)/(n-1)` for randomized `tr(C^2)`. Prefer an exact sample Gram when the number of cue histories is small enough. Keep raw, normalized and readout state clouds separate. For the continuous-tag sensitivity, propagate the cue Jacobian through every input injection; categorical recall requires basin/behavior tests because a local derivative can vanish inside every correctly classified basin.

Start with an exact small CPU Jacobian and covariance benchmark, then matrix-free probes on the same cells, then compact GPU models. Record actual memory, runtime, closure errors and estimator convergence before expanding dimensions or architectures. No performance or cluster-capacity estimate follows from these papers; fused kernels may lack the derivative rules needed by JVP/VJP and require a reference implementation for measurement.
