\section{Related Work}

\textbf{Temporal Graph Learning Methods.}
Temporal Graph Neural Networks (TGNNs) are categorized into continuous and discrete time dynamic graph methods (CTDG and DTDG). CTDG methods process event streams with timestamps using neighbor sampling to model evolving relations. Innovations in this area include TGAT \citep{tgat} that introduced self-attention with temporal encoding, along with TGN \cite{tgn} and TGNv2 \cite{tjandra2024enhancingexpressivitytemporalgraph}, which incorporated memory modules to keep track of a node's past interactions. Other notable approaches in this domain include JODIE \citep{Jodie_Kumar_2019}, which proposed to use recurrent neural networks to learn dynamic user and item embeddings for future interaction prediction, and DyRep \citep{dyrep}, which models the dynamics of node representations using temporal point processes. More recently, DyGFormer \citep{dygformer} proposed to adapt the transformer architecture to perform multi-head attention on one-hop neighbourhood temporal patches, while CTAN \cite{ctan} introduced the idea of employing ODEs to model the continuous evolution of node representations.

DTDG methods, in contrast, operate on regularly-spaced graph snapshots and typically use recurrent neural networks to capture historical information. Popular methods in this category include GC-LSTM \citep{gclstm}, which embeds graph convolutions \cite{gcn} within an LSTM architecture, and T-GCN \citep{tgcn}, which combines graph convolutions with Gated Recurrent Units (GRUs). EvolveGCN \citep{evolvegcn} offers a different approach by using recurrent neural networks to evolve the parameters of the GCN as the temporal graph evolves.

Recently, \cite{huangutg} compared CTDG and DTDG methods and found that DTDG methods sacrifice accuracy for efficiency by computing on coarser-level snapshot information. Subsequently, they showed that DTDG methods can operate on CTDG datasets by using the Unified Temporal Graph (UTG) framework. In \Cref{sec:tgrab}, we evaluate and compare the above methods from both continuous and discrete-time approaches on \benchmarkname datasets to analyze their capabilities in capturing core temporal patterns. 

\textbf{Temporal Graph Benchmarks.} Dedicated benchmarks \citep{Jodie_Kumar_2019, uci, enron, social-evo} have significantly improved TGNN evaluation in the past. However, \cite{poursafaei2022betterevaluationdynamiclink} noted overly optimistic results due to simple negative edges and introduced new sampling strategies and diverse datasets. Following the same vein,  TGB \citep{tgb} presented significantly larger datasets than its predecessors in terms of the number of nodes and edges for node and link prediction. Its successor, TGB~2.0 \citep{tgb2.0}, introduced large-scale datasets for heterogeneous and knowledge graphs. Both TGB and TGB~2.0 expose the fact that current TGNNs perform disappointingly in real-world benchmarks. More recently, TGB-Seq \citep{tgb-seq} proposed real-world with complex sequential dynamics and low edge repeatability, revealing limitations in the generalization capabilities of current TGNNs. Our work complements these recent efforts by constructing synthetic tasks to more exactly pinpoint the current functional weaknesses of TGNNs.

Continuous-Time Dynamic Graph (CTDG) performs computation on a stream of events, each of which is associated with a timestamp. They typically employ neighbor sampling to have access to historical information and subsequently model evolving relations. Many recent architectures operate on this principle: for instance, TGAT \citep{tgat} leverages self-attention with temporal encoding to weigh the importance of historical interactions; TGN \citep{tgn} generalizes this with memory modules to capture long-range temporal dependencies; DyGFormer \citep{dygformer} computes node embeddings by applying multi-head attention \citep{transformer} to temporal patches of a node's first-hop interactions; and CTAN \citep{ctan} frames temporal graph learning as an Ordinary Differential Equation (ODE) to model long-range dependencies.

As opposed to the neighbour sampling done by CTDG methods, DTDG methods typically use a recurrent neural network to keep track of historical information.  Early TGNN approaches such as GC-LSTM \citep{gclstm}, T-GCN \citep{tgcn}, and EvolveGCN \citep{evolvegcn} exemplify this, often combining static GNNs to process the structure within each snapshot with recurrent neural networks to model the evolution across snapshots.
